# Releases

## 0.4.0-beta

- Startup prerequisite checks and automatic recovery of changes made by a failed attempt.
- Main window runs normally; protected operations use helpers with explicit paths.
- Disk protection pauses new streaming transfers and offline downloads by default.
- Local offline copies support single byte-range requests, including suffix ranges and validators.
- Connection diagnostics show CDN addresses, fallback use, successful deliveries, and failure reasons.
- Separate streaming, download, and stop-all actions.
- Accurate delivery counters, larger text, stronger secondary text contrast, and keyboard focus recovery.

## 0.3.0-beta

MW4 Texture Control for 64-bit Windows.

- Guided game selection and session setup.
- Texture streaming with live request and transfer statistics.
- Resumable offline texture downloads.
- Settings, diagnostics, reports, and hosts recovery.
- Windows installer and portable ZIP.
