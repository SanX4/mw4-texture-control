# Usage notice

MW4 Texture Control is intended for offline, single-player use with your own game installation. It includes no game assets, texture packs, keys, or game binaries.

The app reads files from your installation and requests publicly reachable texture URLs. It does not patch or hook the game or read its process memory. Downloaded content remains the property of its rights holders and should remain on your own machine.

Starting a session manages a marked hosts-file entry with a backup. Stopping the session or using Restore hosts removes that entry. One-time game setup is applied through an explicit action in the app.
